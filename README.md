# MNIST Handwritten Digit Classification

A multilayer neural network built from scratch using NumPy to classify handwritten digits from the MNIST dataset.

## Features

- Handwritten digit classification from 0 to 9
- Multilayer neural network implemented from scratch
- One-hot encoded output labels
- Training and test accuracy evaluation
- Confusion matrix for model evaluation

## Results

- Training accuracy: 97.18%
- Test accuracy: 97.07%

## Tech Stack

- Python
- NumPy
- Matplotlib
- Scikit-learn

## Project Files

- Notebook file — Model implementation, training, and evaluation
- Dataset files — MNIST training and test data
- Results — Accuracy metrics and confusion matrix
